# Event Horizon v0.4.0 — Executor Attestation and Public-Artifact Hardening

Event Horizon v0.4.0 turns the prototype into a reproducible public research artifact centered on one claim: local compromise of the sacrificial execution environment should not become transferable authority. Dynamic guardians remain vetoes only; they cannot exceed the deterministic static-policy ceiling.

## Highlights

- Renamed the attestation subsystem and public API to **Executor Attestation**, including the `eh-attest` CLI and `EH_ATTESTATION_*` configuration.
- Replaced caller-controlled trust inference with provider-specific verification dispatch. The simulator returns development trust only; the TPM path returns hardware trust only after quote, key, PCR, freshness, measurement-policy, and whole-bundle checks.
- Added authority-issued, context-bound nonces with durable one-use SQLite transitions across cooperating local verifier processes, and removed stale development-attestation caching.
- Added an authenticated cross-language replay interface, a single-writer reference service, signed checkpoint/epoch rollback defenses, Python replay adapters, and an awaitable TypeScript nonce adapter with Python/Node interoperability tests.
- Hardened capability schemas, canonicalization, Ed25519 key binding, exact request reconstruction, exclusive expiration, and durable insert-once consumption across cooperating local broker processes.
- Added audience-bound Ed25519 authentication and durable one-use nonces for capability, evidence, and certificate mutation requests.
- Removed inline private seeds from service JSON and added restricted file-backed development keys with restart continuity.
- Added fixed public capability vectors, guardian compromise injection, and concurrency regressions.
- Added one npm lockfile, pinned Python dependencies, a CycloneDX SBOM, clean-clone scripts, GitHub Actions, and repository hygiene enforcement.
- Added a single-command process-separated demo with replay, argument widening, executor transfer, prohibited egress, evidence-tampering, teardown, and independent certificate verification.
- Added a bounded safe adversarial interface and an explicitly scripted synthetic baseline-versus-contained experiment format.
- Rewrote the public documentation around functional component names, precise trust boundaries, disclosure rules, limitations, and implementation-level design defense.

## Verification result

The portable local release suite passes 46 TypeScript tests and 83 Python tests. The additional real Linux TPM integration test remains opt-in and was skipped on the Windows release host. All eight TypeScript workspaces build, all eight fixed capability vectors pass, the public demo produces the documented denial/detection summary, and its fresh Ed25519 containment certificate verifies independently.

## Security boundaries that remain

This release is not a production containment system. The default executor uses process separation rather than production Firecracker isolation. The optional Firecracker path is a development target without a production jailer claim. The TPM verifier has a constrained quote-validation path, but physical hardware enrollment, endorsement, fleet policy, and production provenance remain incomplete. Simulator attestation is not hardware attestation. Replay state is durable and atomic across cooperating processes on one host. The remote replay interface authenticates clients and signed checkpoints, but its reference service is one SQLite writer and does not supply consensus, old-leader fencing, protected client checkpoint storage, or a deployed multi-host guarantee. Signing and evidence mutations are authenticated, but the development keys, clients, services, and storage remain under one host account; they are not independently administered, HSM-backed, or physically one-way. No frontier model has been contained, no external audit has occurred, and project-authored automated tests are not independent validation.

The repository retains its pre-existing proprietary source-review license declaration; this release is publicly reviewable but is not presented as open-source software.
